# leetcode_problem_solutions

A collection of LeetCode solutions, interview preparation resources, and company-wise problem sets.

## 📂 Repository Structure

```text
leetcode_problem_solutions/
├── company-problems-1/   # Company-wise interview questions (submodule)
├── company-problems-2/   # Company-wise interview questions (submodule)
└── ...
```

## 📚 Included Resources

This repository includes the following Git submodules:

### Company Problems Repository 1

**Source:** https://github.com/liquidslr/interview-company-wise-problems

Contains company-specific interview questions and LeetCode problems organized by company.

### Company Problems Repository 2

**Source:** https://github.com/snehasishroy/leetcode-companywise-interview-questions

Contains curated company-wise LeetCode interview questions and preparation material.

## 🚀 Clone Repository

Since this repository uses Git submodules, clone it using:

```bash
git clone --recurse-submodules https://github.com/udayshankarpurbey/leetcode_problem_solutions.git
```

## 🔄 Existing Clone?

If you already cloned the repository, initialize submodules with:

```bash
git submodule update --init --recursive
```

## ⬆️ Update Submodules

To fetch the latest changes from the original repositories:

```bash
git submodule update --remote --merge
```
